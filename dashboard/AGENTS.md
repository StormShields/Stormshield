# Lessons: Dashboard

Area gotchas that are still true. Claude Code loads this file (through `CLAUDE.md`) only once a session reads a file in this folder; other agents read the nearest `AGENTS.md`. Add a line when something here breaks, surprises you or takes more than one try; delete a line once your change makes it untrue. Repo-wide lessons: `docs/agents/lessons.md`.

- **The Sandbox Panel shows only when `/api/state` has `sandbox`**; a flow test stubs `/api/sandbox/nodes` and reads circles and links back with `sourceData("radio-range")` and `sourceData("radio-links")`. How the radio layers look lives in `mapStyle.ts`, their colours in `theme.css`.
- **A Region switch remounts the map** (`NodeMap` is keyed on the Region's name) and makes `useCachePack` read the new Hub's pack; a flow test stubs `GET /api/sandbox/regions` and `POST /api/sandbox/region`, and a Hub that refuses (409) puts its `detail`, which carries the build command, in the Panel's alert.
- **Suggested sensor sites come in `/api/sandbox/nodes` as `suggested_sites`** (only those with no Sensor within 50 m); the map draws each as a faint `suggested-site-marker` button whose tap sends the add-Sensor call. Its look is the `--suggested-site*` roles in `theme.css`.
- **A Sandbox Sensor is drawn at its true spot** (from `/api/sandbox/nodes`, the centre of its range circle), not the fuzzed one in `/api/state`. A flow test drops one with `dragMarker(labelElement, lat, lon)` and reads it back with `markerAt`; `MapMarker`'s `onDragEnd` snaps the marker back to its `lat`/`lon` once the drop is handled, so a refused move leaves it where it was.
- **jsdom has no WebGL, canvas, Web Audio or `matchMedia`.** `setup.ts` swaps in `fakeMaplibre.ts`, `fakeViewport.ts` and a mocked `weatherImageUrl`; read back what the app gave the map with `sourceData`, `lastMap().layerIds`, `tapMap`.
- **Fake timers must use `shouldAdvanceTime: true`**, or every `findBy*` hangs into a 5 s timeout. To prove "updates without waiting for the poll", look inside the poll interval with `advanceTimersByTimeAsync(STATE_POLL_MS / 10)`; a `findBy*` passes even when the code is broken.
- **Map assertions wait with `waitFor`.** Check a new test by breaking the code it covers.
- **`localStorage` is cleared after every test** (open Panels are remembered there). A calm day opens only the Readings Panel: call `expandPanel(...)` first.
- **Build test state with `fakeNodeState()` / `fakeNodeSnapshot()`**; a `fetch` stub without `/api/state` stays on "Connecting…". GeoJSON fixtures need `type: "FeatureCollection"`.
- **`theme.test.ts` bans raw colours outside `theme.css`** (even in comments and as `rgba(`) and any `font-family` that is not a theme variable. A new colour is a role in `theme.css` first.
- **ESLint `react-hooks/set-state-in-effect`** rejects setting state at the top of an effect; derive it during render instead.
- **An effect that needs a MapLibre layer from another effect must run after it in the same component** (child effects run first).
- **MapLibre data URLs must be absolute and `{z}/{x}/{y}` must stay literal**: `new URL(...)` percent-encodes the braces and the map silently loses its terrain.
- **Every map fill, line width and opacity lives in `mapStyle.ts`**, with the theme roles it reads (`readMapColors`); `basemap.ts` only adds the pack's sources. The pack's places carry no "key" flag, so `placeLabels.ts` names them by kind and zoom.
- **No MapLibre text layers** (they need a glyph server); labels are DOM markers placed by `labelPlacement.ts`.
- **Browsers play no sound until the first tap**; sound code must warn, never throw, without Web Audio.
- **`findLast` is not in the TypeScript lib target**: use `.filter(...).at(-1)`.
- **Icons are `lucide-react`, pinned exact.** Fonts are bundled `@fontsource` files; the page makes no request to another host.
- **Time zone and units come from the Region** (`useRegion()`, `regionTime.ts`, `displayUnits.ts`); `NodeOnMap` keeps cm/mm/hPa for logic and carries `shown` strings for screen. Intl spells Kathmandu "GMT+5:45" and September "Sept" in en-GB, so `regionTime.ts` supplies "NPT" and its own month names. `fakeNodeState` is Fort Myers (`FAKE_REGION`); a flow test about the river uses `nepalNodeState` (`NEPAL_REGION`, `flash_flood`). On a coast Region a simulated Sensor card with readings but no `water_level` reads "Water level: dry"; a real Sensor, or one on a river, shows nothing, since it may have no water gauge.
- **The coast Water ETA is built on the device** (`coastWaterEta.ts`, `useCoastWaterEta.ts`): the home's ground comes from the pack's elevation tile (`groundHeight.ts`), the rate from the nearest Registered Node's levels kept by Event time, and the Region's `storm_surge` summary (`rising_window_s`, `flood_prone_below_cm`) from `/api/state`. A flow test stubs `createImageBitmap` and `OffscreenCanvas` to give a tile pixel; ground above `flood_prone_below_cm` (9 ft at Fort Myers) has no ETA, so pick test ground below it.
- **Vitest runs under Node 22 in CI; test locally with it** (`npx --yes node@22 node_modules/vitest/vitest.mjs run`). A fetch stub must not build a `Response` from a jsdom `Blob` (`object.stream is not a function` on Node 22); give it a string body. A flow test mutes `console.error`, so print it when a test fails without a clue.
